Athena — User Data Deletion

Last updated: 3 November 2026

Athena stores Instagram-related data only on the operator’s private installation. To delete that data, follow the steps below.

1. Disconnect Instagram from Athena

  1. Open Athena → Account
  2. Disconnect / remove the connected Instagram account

2. Revoke app access in Meta / Instagram

  1. Open Instagram or Meta account settings → Apps and websites (or Business integrations)
  2. Remove / revoke access for the Athena app

3. Delete local Athena data

On the server that runs Athena, delete the application data directory (posts, comments, analyses, encrypted tokens, and related files) or remove the Athena deployment entirely. After that, no Instagram content or tokens from Athena remain on that installation.

4. Requests

If you need help confirming deletion, contact the operator via the GitHub account that hosts this page. Deletion is usually completed as soon as the steps above are performed on the private installation.
