Athena Privacy Policy

Last updated: 3 November 2026

Athena is a personal tool for managing and analyzing the operator’s own Instagram professional account. It is not offered as a public multi-user service.

1. Who we are

Athena is operated by the account owner for private use on a local or private network (for example, a home NAS). Contact for privacy questions: via the GitHub account that hosts this policy page.

2. Data we process

Depending on connected features, Athena may process:

  • Instagram account identifiers and username
  • Media metadata (captions, timestamps, permalinks, metrics)
  • Comments on the operator’s own media
  • OAuth access tokens needed to call Instagram / Meta APIs
  • Optional analysis text and settings stored by the operator

3. Purpose

Data is used only to:

  • Synchronize and display the operator’s Instagram content and metrics
  • Support planning, reuse, and AI-assisted analysis for that same account
  • Authenticate the operator to Athena’s local admin interface

4. Sharing

Athena does not sell personal data. Instagram-related data is sent to Meta (Instagram Graph API) as required to provide the requested features. Optional AI features may send prompts and selected content to the configured LLM provider. Data is not shared with other third parties except as needed to run those integrations or as required by law.

5. Storage and retention

Data and tokens are stored on infrastructure controlled by the operator (for example, encrypted storage on a private server). Retention is under the operator’s control; data can be deleted by removing Athena’s local data and disconnecting Instagram access in Meta / Instagram settings.

6. Security

Access to Athena is protected by local admin credentials. Instagram access tokens are stored encrypted and are not exposed to the browser client.

7. Your rights

Because Athena is a personal installation, the operator can review, export, or delete stored data directly on their server and revoke Instagram permissions at any time in Instagram / Meta account settings.

8. Changes

This policy may be updated when Athena’s data practices change. The “Last updated” date at the top will be revised accordingly.
